May release

A smaller surface, a stronger foundation

This month is about clarity over volume. Lemonade Framework now ships a tighter email API, more explicit component contracts and examples that can be read alongside their generated output.

The main story: email composition without template drift

Typed, immutable components now cover multi-action groups and accessible process steps while preserving one renderer registry and predictable HTML output.

The release notes explain the design decisions, validation rules and compatibility boundaries behind the new API. No client-specific markup leaks into application code.
